# Team Working Agreement

## Communication
- Primary channel: [Írd be: pl. Discord / Messenger]
- A blocked task is reported within one working day.

## Work tracking
- Important development work starts from a GitHub Issue.
- The Project board must reflect the real status of work.
- One person should not keep several unrelated items In Progress.

## Git baseline
- Commit messages describe the intent of the change.
- Secrets and local env files are never committed.
- From the PR week onward, feature work is merged through Pull Requests.

## Definition of Done - Week 1 baseline
A work item is Done when:
- [ ] the expected repository change exists;
- [ ] related documentation is updated;
- [ ] no secret or local-only file is committed;
- [ ] another team member can understand what changed;
- [ ] the Issue and Project status reflect reality.
